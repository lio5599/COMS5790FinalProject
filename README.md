# COMS5790FinalProject
Final project for natural language processing, COMS5790.

## How to run

1. Install Node.js 20 or newer.
2. `git clone https://github.com/lio5599/COMS5790FinalProject.git`
3. `cd COMS5790FinalProject`
4. `npm install`
5. `npm run dev` and open the localhost link
6. `npm test` to run the tests

Don't run `npm create vite`: the project is already set up.

## Team workflow

- Work on your own branch and open pull requests into `main`.
- Display code goes in `src/display/`, annotation in `src/annotation/`, and file handling in `src/io/`.
- Changes to `src/types.ts` need everyone's OK.
